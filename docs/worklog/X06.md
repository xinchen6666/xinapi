## 实现

- CPR 新增订阅预览链路：`model/subscriptions.rs` 负责格式判定、节点模型、限额与目标策略；`ports/subscription.rs` 定义下载端口；`use_case/subscriptions/{mod.rs,parse.rs}` 负责编排与解析；`gateway-host/subscription_fetch.rs` 负责受限下载；`gateway-api/src/admin/subscriptions.rs` 提供固定路由与 wire 合同。
- 解析覆盖 Clash YAML、Clash JSON、URI 列表与 Base64 文档；文档内 `proxy-providers` 按同一预算与同一策略拉取并物化成具体节点，深度限一层；rules、rule-providers、脚本、监听与文件路径一律跳过。逐节点给出展示名、协议与可用标记，诊断码覆盖 `unsupported_protocol`、`node_parse_error`、`provider_fetch_failed` 与文档级错误。
- 下载边界：默认 https；明文 http 仅对配置项 `subscriptions.insecure_test_hosts` 列出的测试主机开放，默认空列表；正文 2 MiB、解压后 8 MiB、整次预算 10 秒、跳转上限 3 且逐跳复核目标；请求只带固定协商头，地址内凭据在发起前丢弃；响应只含节点名、协议、可用标记与诊断，主机、端口与凭据留在 CPR。
- 新增依赖 `url`、`percent-encoding`、`yaml-rust2`，三者原本已在 `Cargo.lock` 锁定图内，锁定文件仅增加三条依赖边。配置模板 `deploy/config.example.yaml` 与 `docs/api.md` 同步说明新接口与新配置。
- New API 新增 `POST /api/account-egress/subscription-preview`：沿用 `handlePermissionRoute`、`middleware.AdminAuth()` 与 `authz.AccountEgressRead`；`dto/account_egress.go` 定义白名单结构；`service/cpr_readonly.go` 抽出共用的管理 Key 读取，新增 20 秒预览客户端与 CPR `reason` 到管理端消息的映射；CPR 其余字段在解码期丢弃。
- 前端新增 `web/src/features/subscription-preview/` 与 `/subscription-preview` 路由、管理菜单入口与七语文案，复用 `SectionPageLayout`、`DataTablePage`、`useDataTable`、`Tabs`、`ErrorState`、`StatusBadge` 等既有组件；按协议分组用页签加计数表达，保持默认移动列表。

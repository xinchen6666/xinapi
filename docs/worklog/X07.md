## 实现

- Admin 增加来源摘要、待审核结果、节点身份、连接版本与批准集合。新下载结果只进入待审版本，批准时才更新当前节点；相同内容重复批准复用原批准版本。
- 解析器保留私有规范连接文档，统一主机大小写、数值端口、协议别名、UUID 和已明确默认值。公共预览继续使用显式白名单；原始名称、顺序与节点 ID 相互独立。超出已支持传输选项的字段给出静态诊断。
- 首版用结构化字段直接比较身份关系。唯一连接对应提供建议；同名连接变化或重复候选需人工选择旧身份或新 UUID；旧连接版本仅追加，新版本与原节点绑定由显式批准决定。
- 来源整体文档由 Store 使用 ring AES-256-GCM 密文持久化。独立部署密钥首次创建于运行数据目录，0600、32 字节。随机 nonce 与来源 UUID/用途 AAD 绑定文档。已有密文的读取、更新或新来源创建均使用原部署密钥；缺失或认证失败明确报错。
- Store 中来源 revision 的条件写入、历史版本保留与审计位于同一数据库事务。配置写入按全局配置行、来源行的顺序加锁；旧刷新即使较晚结束也只返回 409。刷新失败和待审结果保留原批准版本。
- 添加迁移 [0046](../../services/codex-proxy-rs/backend/migrations/0046_subscription_sources.sql)，创建 subscription_sources 表。现有迁移文件保持原样；按当前用户约定保留历史摘要清单，新增条目的手工摘要操作省略。
- New API 同页增加「来源管理」，普通管理员读取摘要和详情；来源写入采用超级管理员登录会话。读取 scope 的个人访问令牌在四条写入路由统一拒绝。界面使用既有 DataTable、Dialog、ConfirmDialog 和七语文案。
- 页面列出改名、新增、连接变化、歧义与缺失节点。完整来源移出旧节点时需确认停用；部分来源批准需确认接受范围并保留其余旧节点。来源 URL 输入提交后清空，读取接口只返回元数据。

## 自审修订

独立只读复核由 x07-review-domain 与 x07-review-storage 执行；已处理能力诊断和完整性条件混用、读取令牌写入授权、连接默认值等价、重复节点关系放大、密钥缺失/归属与相同内容重复批准耗尽历史等问题。

当前资源预算：128 个来源；每来源 4096 个节点身份；一次待审核结果最多 32768 条候选到旧节点映射；公开响应 8 MiB；密文来源文档 32 MiB。关系预算在复制 UUID 列表前检查，公开 JSON 先流式计量，再写入。容量错误保持原来源状态。
